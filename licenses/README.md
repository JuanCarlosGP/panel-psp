# Componentes de terceros

- Las fuentes de mapa de bits proceden de Liberation Sans. El archivo `FONT-LICENSE.txt` de Panel PSP contiene el aviso y la licencia SIL Open Font License 1.1.
- El ejecutable se compiló con [PSPDEV v20261001](https://github.com/pspdev/pspdev/releases/tag/v20261001). Los avisos de PSPSDK, Newlib y la biblioteca de ejecución de GCC están en esta carpeta.
- Las tablas de importación de `KUBridge` y `SystemCtrlForUser` proceden de [psp-cfw-sdk](https://github.com/pspdev/psp-cfw-sdk). La consola resuelve esas funciones al ejecutar la aplicación con [ARK-5](https://github.com/PSP-Arkfive/ARK-5).
